# 论文选题方法论

一套帮助研究者从文献阅读中发现问题、生成候选课题并完成可行性筛选的方法。

核心流程：**远观领域地图 → 近观具体论文 → 结构化生成创新点 → 可行性验证 → 迭代收敛课题**。

适合正在经历以下问题的研究者：

- 文献看了很多，却迟迟无法确定课题；
- 总觉得创新点不够新；
- 课题过大、过难，不知道何时调整或止损。
