# `find-a-paper` 技能

从宽泛研究方向、近年综述或种子论文中发现、查证并筛选可行的论文课题，但不代替系统综述、导师决策或完整论文研究。

## 适合用它做什么

- 在只有一个宽泛领域、暂时没有论文思路时建立研究版图。
- 从近年综述中寻找值得继续下钻的研究分支。
- 从一篇种子论文的假设、方法、数据、指标或局限出发寻找创新点。
- 比较多个候选题目的新颖性、实验成本、数据条件和完成风险。
- 将模糊想法改写成可证伪的研究问题和最小验证实验。
- 在正式投入复现和实验前，对课题进行初步可行性筛查。

## 典型请求

- “使用 `$find-a-paper` 帮我探索软件工程方向的论文课题。”
- “我想研究大模型可靠性，请从近三年的研究版图中找几个可行切入点。”
- “基于这篇论文继续向下挖，看看还能增加、替换或比较哪些因素。”
- “比较这三个题目的创新性、数据要求、算力成本和毕业风险。”
- “检查这个研究问题是否已经有人做过，并设计一个最小验证实验。”

## 你需要提供

最低限度只需提供一个研究领域或关键词。为了得到更准确的结果，建议补充：

- 学历阶段和课题目标，例如课程论文、本科毕业论文、硕士论文或投稿论文；
- 预计完成时间；
- 可用的计算设备、经费、数据和实验环境；
- 导师或团队擅长的方向；
- 已阅读的综述、种子论文、模型、数据集或实验现象；
- 更偏好的研究类型，例如实证研究、工具开发、算法改进或理论分析；
- 不能接受的方向或资源限制。

信息不完整时，技能会采用保守假设并明确标注；只有缺失信息会实质改变检索方向或可行性判断时，才需要进一步确认。

## 产出

根据任务规模，通常会给出：

- 研究方向的分层版图，以及值得精读的具体分支；
- 3–5 个经过初步检索的候选研究问题；
- 每个问题的来源路径：远观下钻或对种子论文的受控变换；
- 可核查的论文、数据集、基准或官方资料；
- 核心假设、可能机制和可证伪条件；
- 最小验证实验、基线、对照组和评价指标；
- 新颖性、算力、数据、工程、伦理和时间风险；
- 带理由的候选排序，以及首选题目的下一步行动和停止条件。

## 边界

- 不用于只查找一篇标题、作者或 DOI 已知的论文。
- 初步检索无法证明“绝对无人研究过”；结论会限定数据库、关键词和时间范围。
- 不编造论文、引用、DOI、实验数据或新颖性结论；无法访问全文时会区分摘要证据与全文证据。
- 不把简单替换模型、数据集或提示词自动视为创新，必须解释作用机制和可验证差异。
- 不保证候选课题一定能够发表，也不替代导师、伦理委员会或领域专家的最终判断。
- 不自动完成完整复现、正式实验或论文写作；这些工作需要用户继续授权并提供相应资源。

## 相关技能

- `$zotero`：检索本地 Zotero 文献库、导出 BibTeX、读取已索引全文和管理引用。
- `$pdf`：阅读、提取和检查论文 PDF，适合进入种子论文精读阶段。
- `$hf-cli`：查找或管理 Hugging Face 上的模型、数据集、论文与实验资源。
- `$aigc-reduce`：论文成稿后降低模板化表达和 AI 痕迹，不负责发现研究问题。
