# 论文选题方法论

目标是把模糊方向转化为有限数量、能够比较、可以验证且符合用户资源条件的候选课题。核心循环是：

> 远观研究空间，近观具体机制，结构化生成差异，筛选可行性，迭代收敛。

## 工作原则

- 把“方向”“问题”“题目”分开。方向规定范围，问题提出可检验关系，题目是问题的简洁表达。
- 不把“没人做”直接当成创新。空白还需要研究价值、合理机制和可验证证据。
- 不把换模型、换数据集或换对象自动视为贡献。必须说明新条件带来的独特困难及预期机制。
- 不等待绝对确定。达到“问题明确、资源可得、实验可做、价值可解释”后，进入最小实验。
- 未检索近期文献时，不宣称课题具有新颖性。需要判断研究现状时，检索近期综述、代表论文及最接近工作，并区分事实与推断。

## 第一步：明确边界

从用户已有材料中提取以下条件；仅在缺失信息会显著改变结果时再询问：

- 研究领域与已有基础；
- 学位阶段、时间窗口和目标成果；
- 可用数据、算力、设备、资金和专家支持；
- 用户偏好的理论、方法、系统或应用型研究；
- 已读综述、种子论文和已有想法。

把约束写成选题筛选条件，不要只作为背景描述。

## 第二步：远观研究空间

阅读近期综述与代表性工作，建立领域地图。分类维度可包括研究对象、任务、方法、数据、应用场景、语言、评价方式和验证层级。

远观需要回答：

1. 领域有哪些主要路线和层级？
2. 哪些对象或场景覆盖充分，哪些覆盖不足？
3. 哪些类别之间存在尚未研究的组合？
4. 顶层没有机会时，可以沿哪个维度继续下钻？

输出分类依据和边界，避免只罗列论文标题。远观得到的是候选研究空间，不是最终课题。

## 第三步：近观具体论文

选择与用户资源最接近的代表论文，拆解：

- 研究对象与任务；
- 核心假设和作用机制；
- 数据、变量、模型或算法部件；
- 基线、指标、对照和消融；
- 实验条件、边界和失败情形；
- 作者承认的局限，以及论文没有讨论的隐含限制。

继续追问“为什么有效”“在哪些条件下失效”“哪些环节没有验证”。近观的目标是找到可修改、可替换、可扩展或可质疑的具体部件。

## 第四步：结构化生成候选问题

使用以下操作生成候选问题，不要求每次全部使用：

| 操作 | 含义 |
|---|---|
| 加 | 增加变量、约束、模块、数据源或指标 |
| 减 | 删除复杂环节，降低成本或依赖 |
| 换 | 替换模型、公式、算法、数据或对象 |
| 组 | 组合已有方法或机制 |
| 比 | 横向比较、消融或边界测试 |
| 迁 | 迁移到新任务、语言、领域或场景 |
| 反 | 验证评价器、验证器或原假设本身 |
| 分 | 把笼统问题细分到特定条件或层级 |
| 升 | 从个别方法提炼框架、解释或分类体系 |

每个候选问题必须补全四项：

1. 为什么需要改变？
2. 它解决哪个已观察到的缺陷？
3. 为什么预期有效？
4. 用什么证据检验？

无法补全这四项的想法只保留为灵感，不进入正式候选池。

## 第五步：改写为研究问题

使用以下结构收紧候选课题：

> 在【具体场景】中，现有【方法】由于【已观察到的局限】，会导致【可测量后果】。拟引入或改变【核心变量或机制】，通过【数据、基线、指标与对照】检验其能否改善【目标】，并分析其在【边界条件】下是否成立。

题目至少要明确：研究对象、现有缺陷、拟议方法、应用条件和验证方式。

## 第六步：可行性筛选

对每个候选题给出“通过、条件通过或不通过”，并说明证据与不确定性。

| 维度 | 关键问题 |
|---|---|
| 新颖性 | 是否已有高度相似工作？差异是否实质影响研究结论？ |
| 研究价值 | 缺陷是否真实、重要且具有一定普遍性？ |
| 技术可行性 | 假设是否合理？方法、基线和指标能否实现？ |
| 资源可行性 | 数据、算力、资金、时间和专家支持是否可获得？ |
| 实验可验证性 | 能否形成可证伪假设、对照和消融？负结果是否仍有解释价值？ |

不要只给总分。指出每个候选题的致命风险、可降低风险的修改方式，以及最小可行实验。

## 第七步：止损与迭代

帮助用户在开始前设定期限、交付物和退出条件：

- 阅读止损：到达预设周期仍写不出候选问题，暂停扩大检索，转为分类和比较。
- 创新止损：多轮修改后仍说不清解决什么缺陷，淘汰或搁置该想法。
- 复现止损：基线超过预设期限仍无法跑通，记录原因，更换可靠基线或缩小范围。
- 资源止损：关键数据、算力或专家无法获得，调整对象、方法或验证方式。
- 难度止损：最小实验无法在可接受时间内完成，优先降级课题，不必立即放弃整个方向。

保留一个主课题、一个降级方案和一个替代方案。新证据出现时重新比较，不因单篇新论文频繁换题。

## 默认输出

根据任务规模选择合适篇幅，通常包括：

1. 研究空间的简要分类；
2. 3 至 8 个候选研究问题及其生成依据；
3. 候选题可行性比较表；
4. 推荐的主课题、降级方案和替代方案；
5. 主课题的最小可行实验、所需资源和止损条件；
6. 尚未验证的假设与下一轮检索关键词。

结论要说明为什么推荐某个课题，也要说明放弃其他课题的理由。若证据不足，明确标注“待验证”，不要用确定语气包装推测。
