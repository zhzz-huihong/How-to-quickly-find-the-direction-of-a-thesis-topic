# Research Topic Selection

一个用于论文选题的 Codex Skill。它帮助研究者从综述、研究方向或种子论文出发，建立研究地图、生成候选问题、评估可行性，并逐步收敛到能够完成的课题。

## 适用场景

- 文献看了很多，仍然无法确定课题；
- 找不到创新点，或总觉得想法不够新；
- 导师给出的方向过于宽泛；
- 课题过大、过难，需要缩小范围；
- 需要比较多个候选题并设置止损条件。

## 核心方法

```text
远观研究空间
    ↓
近观具体论文
    ↓
加、减、换、组、比、迁、反、分、升
    ↓
生成候选课题
    ↓
新颖性、价值、技术、资源与实验筛选
    ↓
主课题 + 降级方案 + 替代方案
```

Skill 不会把“没人做”“换模型”或“换数据集”直接视为创新。每个候选问题都需要说明研究缺陷、作用机制、验证证据和适用边界。

## 使用方式

```text
使用 $research-topic-selection 帮我从“大模型可靠性验证”中寻找可行课题。
```

```text
使用 $research-topic-selection 分析这篇种子论文，生成候选创新点，并按可行性排序。
```

```text
使用 $research-topic-selection 评估我的课题是否过大，并给出降级方案和最小实验。
```

## 默认输出

- 研究空间分类；
- 3 至 8 个候选研究问题；
- 可行性比较表；
- 推荐的主课题、降级方案和替代方案；
- 最小可行实验、资源需求和止损条件；
- 尚待验证的假设与检索关键词。
